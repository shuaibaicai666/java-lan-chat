# 测试与评测集（验收测试用例）

> 对应 spec-skill.md 的验收标准。由 `chat.test.TestRunner` 自动化执行，
> 结果格式：`[PASS] / [FAIL]`，汇总输出通过率。全部用例通过方可交付。

## 环境

- 本机回环网络 127.0.0.1，服务器端口 18888（测试专用，避免与演示端口冲突）
- 心跳超时在测试模式下缩短为 2 秒（服务器参数 `--heartbeat-timeout 2`）

## 用例列表

| 编号 | 用例名 | 对应需求 | 步骤 | 期望结果 |
|---|---|---|---|---|
| T01 | 登录成功 | FR1 | 客户端 A 以合法昵称登录 | 收到 `WELCOME`，收到包含自己的 `USERLIST` |
| T02 | 重名拒绝 | FR1/SR1 | B 用与 A 相同的昵称登录 | 收到 `ERROR`（含"已被使用"），连接被服务器断开，A 的在线列表不变 |
| T03 | 群聊广播 | FR2 | A、B、C 在线，A 发送群聊消息 | A、B、C 三人都收到 `CHAT\|A\|内容` |
| T04 | 私聊定向 | FR3 | A 发送 `PRIVATE` 给 B | B 收到 `PRIVATE\|A\|内容`；C 在等待窗口内**收不到**任何私聊消息 |
| T05 | 列表同步（上线） | FR4 | C 登录后 | A、B 收到更新后的 `USERLIST`，包含 C |
| T06 | 列表同步（下线） | FR4/FR5 | B 主动 LOGOUT | A、C 收到 `SYSTEM` 下线通知与不含 B 的新 `USERLIST` |
| T07 | 心跳保活 | FR6 | 客户端正常发送 PING | 收到 `PONG`，且在超时时间内不被服务器踢除 |
| T08 | 异常掉线踢除 | FR6 | 客户端停止一切发送（模拟进程崩溃） | 超过心跳超时（2s）后服务器踢除该用户，其他客户端收到新 `USERLIST` |
| T09 | 昵称校验 | SR1 | 依次尝试空昵称、含 `\|`、含 `,`、含 `@`、超过 16 字符 | 均收到 `ERROR`，服务器存活 |
| T10 | 畸形协议鲁棒性 | SR2 | 发送 `PRIVATE` 但缺参数、发送未知指令 `FOO` | 收到 `ERROR` 提示；服务器不崩溃，A 仍可正常群聊 |
| T11 | 并发压力 | PR1 | 一次性连接 30 个客户端 | 全部登录成功；一条广播被 30 个客户端全部收到；广播往返延迟 < 1s |
| T12 | 端口错误处理 | 高风险点1 | 在已占用端口上再启动服务器 | 服务器输出明确错误并退出，不静默换端口 |

## 评测指标

- 通过率 = PASS 数 / 总用例数，目标 **100%**
- T11 附广播延迟测量（毫秒），写入报告
